# PG Manager

A system to help manage **PG (paying-guest) accommodations**.

> **Fresh start.** This repo currently contains a minimal "Hello World" server
> as a placeholder while the PG management system is built out.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000

## Deploy

Auto-deploys to Render on every push to `main` (see `render.yaml`).
